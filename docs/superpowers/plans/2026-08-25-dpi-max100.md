# DPI max100 Suricata Rules Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify a <=100-rule Suricata 8 DPI bundle covering all 39 source protocol/service labels with deterministic PCAP regression tests.

**Architecture:** A declarative inventory maps 39 historical labels to normalized detectors. The ruleset combines Suricata application-protocol detection, compound raw protocol invariants, and narrowly scoped TLS-SNI service rules. A Scapy generator creates one or more positive PCAPs per detector and negative traffic; a validator replays each PCAP through Suricata and rejects both missing expected alerts and cross-detector false positives.

**Tech Stack:** Suricata 8.x, Python 3, Scapy, pytest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-25-dpi-max100-design.md`

## Global Constraints

- Exactly 39 historical source labels must be present in the inventory.
- No more than 100 active Suricata rules.
- New local SIDs are unique and live in 9500001-9500999.
- Rules are port-independent except where the protocol itself embeds no useful discriminator and no safe alternative exists.
- Lab IP addresses, dates, random captures, and weak generic TLS record fragments are forbidden as discriminators.
- A CI pass means zero cross-detector false positives on the committed generated regression matrix; it is not a universal zero-FP guarantee.

### Task 3: Deterministic PCAP corpus

**Interfaces:**

- [ ] Implement deterministic TCP/UDP packet builders with correct flow direction.
- [ ] Generate protocol-specific payloads for all normalized protocol detectors.

- [ ] Generate unrelated TCP/UDP noise samples.
- [ ] Add generation to CI.

### Task 4: Suricata replay oracle

**Files:**
- Create: `dpi-max100/validate_alerts.py`

**Interfaces:**
- Consumes: rules path, cases manifest, Suricata config path.
- Produces: `dpi-max100/artifacts/report.json`, `report.md`, and per-PCAP EVE directories; exits nonzero on missing required alerts or unexpected DPI alerts.

- [ ] Run `suricata -T` before replay.
- [ ] Replay every PCAP with checksum validation disabled for generated packets.
- [ ] Parse only alerts whose signatures start with `DPI|`.
- [ ] Fail when required detectors are absent or when a detector outside the case's allowed set appears.
- [ ] Emit TP/FP summaries and per-case diagnostics.
