# ExamClips — лекции в законченные микроуроки

**Рабочий сайт:** https://examclips.dpdns.org/
**Репозиторий:** `MakSoS1/analytics_test`
**Ветка кода и публикации:** `feat/examclips-library-zoom-storyboard-20261017`
**Корень приложения:** `apps/examclips/` (ранее `examclips-local/`).

Это самостоятельное Vite SPA. Оно читает выбранное пользователем видео,
распознаёт речь локально, предлагает законченные микротемы, позволяет проверить
границы и экспортировать вертикальные MP4 с исходным звуком и вебкой лектора.
Основной проект `analytics_test/main` и сайт `forgeofeducation.ru` отделены от него.

## Начало работы

Нужен Node.js 22.12+ или 24 LTS. Команды выполняются **из этого каталога**:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run dev
```

Vite слушает только loopback. Обычно это `http://127.0.0.1:5173/`;
при занятом порте используйте адрес, напечатанный в терминале.
На Windows можно запустить `START_WINDOWS.cmd` в этой папке.

```sh
npm test
EXAMCLIPS_BASE=./ npm run build
npm run preview
```

В PowerShell: `$env:EXAMCLIPS_BASE='./'; npm run build`.
Первая загрузка Whisper/OCR может скачать публичные модели. Исходное видео
не отправляется на сервер. Доступ к моделям требует отдельной проверки сети.

## Текущая логика и ограничения

Основной планировщик — [src/general-topics.js](src/general-topics.js).
Он использует предложения, речевые переходы и визуальные подсказки, а не
Docker-словарь, имя файла или фиксированные таймкоды. Старые планировщики сохранены
для сравнения и регрессий. Количество роликов и максимальная длина урока не заданы:
цельное решение задачи может длиться существенно дольше Shorts.

Предложения остаются в статусе ручной проверки. Эвристика не гарантирует
смысловую полноту для произвольной лекции; OCR и ASR могут ошибаться.
Нужно проверять начало/конец, читаемость кода и схем, звук и субтитры.

По умолчанию показывается одна основная область исходника, спокойный тёмный фон,
титульник только первые 1,6 секунды и широкая вебка под субтитрами. Предпросмотр
и MP4 используют один композитор. Для AAC в Яндекс Браузере есть проверка реального
декодирования и локальный Web Audio fallback порциями до 30 секунд.
