# Документация ExamClips

Текущий сайт: https://examclips.dpdns.org/. Код и эта документация находятся
в `apps/examclips/` ветки `feat/examclips-library-zoom-storyboard-20261017`
репозитория `MakSoS1/analytics_test`. `main` принадлежит другому проекту.

| Задача | Документ |
| --- | --- |
| Первый запуск, обзор продукта | [README приложения](../README.md) |
| Передать работу агенту | [AGENTS.md](../AGENTS.md) |
| Найти нужный модуль | [architecture.md](architecture.md) |
| Разрабатывать, включить OCR/ASR, запустить тесты | [development.md](development.md) |
| Опубликовать сайт, проверить домен, откатить | [deployment.md](deployment.md) |
| Проверить смысл и изображение, понять ограничения | [quality.md](quality.md) |
| Ошибка в браузере или локальном запуске | [troubleshooting.md](troubleshooting.md) |
| Понять прежние решения и замеры | [history/README.md](history/README.md) |
| Проверить выполненный перенос структуры | [maintenance/2026-10-24-repository-organization.md](maintenance/2026-10-24-repository-organization.md) |

Рабочие инструкции находятся в этом каталоге. Архив не задаёт текущую логику:
например, документы v0.10 описывают Docker-ориентированный планировщик и два
панеля на экране, которые позже заменены общим планировщиком и одной областью.
