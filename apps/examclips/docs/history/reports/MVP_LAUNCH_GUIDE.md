# ExamClips MVP — инструкция и размещение

## Быстро попробовать сейчас

Готовая статическая сборка доступна в артефактах успешного теста: https://github.com/MakSoS1/analytics_test/actions/runs/38877752227

На Windows с Python 3.11 откройте локальный собранный сайт через HTTP-сервер (не через file://). В беседе ChatGPT также выдан ZIP «ExamClips_MVP_Ready_To_Try.zip» со встроенным START_EXAMCLIPS_WINDOWS.cmd.

## Бесплатный хостинг (владелец репозитория: одно действие)

Готовая собранная версия **уже записана в отдельную ветку gh-pages** репозитория; это не сырой исходный код. Ветки и compiled assets проверены.

1. Откройте https://github.com/MakSoS1/analytics_test/settings/pages
2. В разделе Build and deployment выберите **Source: Deploy from a branch**.
3. Выберите **Branch: gh-pages** и **Folder: /(root)**, затем Save.
4. Дождитесь публикации GitHub Pages и проверьте адрес **https://maksos1.github.io/analytics_test/**.

До выполнения шага 2–3 сайт **не опубликован**. Не выдавайте предполагаемый адрес за действующий сайт. Рабочий Pages-URL становится известен после успешного публичного открытия.

CI: .github/workflows/examclips-gh-pages-branch.yml автоматически обновляет gh-pages при изменениях source ветки feat/examclips-mvp-ui-deploy-20261016. Для первого включения не требуется внешний хостинг или GitHub токен.

## Что реально работает в браузере

- Импорт локального MP4/MOV/WebM и SRT.
- Локальный Whisper Tiny/Base (первый раз скачивает публичные веса) и обработка короткими окнами с сохранением прогресса.
- Предварительная смысловая нарезка 1–5 минут по транскрипту и сменам визуальных сцен.
- Локальный Tesseract.js для доски, слайдов, текста, вкладок и кодовых блоков.
- 9:16 компоновка с оригинальными кадрами, движущейся вебкой и оригинальным звуком.
- MP4 720p/1080p, экспорт одной или нескольких микротем при поддержке браузера.
- Локальные мини-тесты по терминам и экспорт их JSON.
- Проверка человеком границ и качества до публикации.

## Отличия локального запуска от бесплатной страницы

На опубликованном статическом сайте оригинальное видео остаётся на компьютере посетителя. **Whisper и Tesseract.js выполняются в браузере**, без прикрепления файла к серверу. Исключения: первая загрузка публичных весов моделей, открытие HTML/CSS/JS с хостинга. Не обещайте полное отсутствие сетевых запросов.

Ollama и изолированный RapidOCR подключаются **только в полноценном локальном запуске из репозитория через START_WINDOWS.cmd**; на публичной статической странице эти опции не изображаются как доступные.
